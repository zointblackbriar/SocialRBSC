## INFORMATION 

The main purpose of this project is to demonstrate the SocialRbSC language properties such as social agents, compartments,
roles, societies in a predefined dynamic environment to create role-based agent-oriented applications.

You can use this project for Social RbSC annotations in order to program with social agents,
role-compartments and smart contracts.

> **Important:** annotation classes (`socialrbscdeterministic.mas.annotation` and
> `socialrbscdeterministic.rolecompartment`) are sourced from the compiled
> **SocialRBSC-core** JAR and are not copied into this examples repository.
> Build/install the core project (`mvn clean install -DskipTests` in the root) so
> that the dependency defined in this `pom.xml` can resolve them automatically.
